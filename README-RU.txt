QWLEY SHADE — версия со скачиванием из GitHub

УСТАНОВКА
Замените файлы сайта содержимым архива и выполните Redeploy на Vercel.
index.html, api/ и assets/ должны лежать в корне проекта.
Для HTML-проекта: Framework Preset = Other, Build Command пустой, Output Directory = .
Дизайн, логотип, скриншот, видео и GitHub-чейнджлог сохранены.
Если есть собственный package.json, удалите только ненужную зависимость @vercel/blob;
не затирайте другие зависимости вашего проекта.
BLOB_READ_WRITE_TOKEN и BLOB_STORE_ID больше не нужны этому сайту.
Удалите их из проекта, если они не используются другими функциями. Старый опубликованный токен отзовите.

ВЫБОР ФАЙЛА
API определяет основную ветку репозитория и ищет файл по расширению .ipa или .apk
по всему дереву этой ветки, включая подпапки. Имя может быть любым.
Оставляйте РОВНО ОДИН актуальный файл нужного расширения в каждом репозитории.
При двух и более файлах сайт не угадывает версию: показывает понятную ошибку.
Удаленные файлы из истории Git не учитываются — смотрится текущее дерево ветки.
После замены/переименования файла обновление может занять до 60 секунд (серверный кэш).

Git LFS поддержан: адрес скачивания использует GitHub raw route, который отдает
содержимое LFS, а не текст указателя. Размер файла берется из LFS-указателя.
Сам LFS-объект должен быть загружен на GitHub, и лимиты LFS аккаунта должны позволять скачивание.
При добавлении нового имени настройте Git LFS и для него: можно использовать
правила *.ipa filter=lfs diff=lfs merge=lfs -text и *.apk filter=lfs diff=lfs merge=lfs -text
в соответствующих .gitattributes. Архив сайта не меняет файлы репозиториев приложений.

ТОКЕНЫ И ЛИМИТЫ
Для публичных репозиториев токен не обязателен. GitHub ограничивает запросы без авторизации.
Если лимита не хватает, добавьте GITHUB_TOKEN только в серверные Environment Variables Vercel
и выполните Redeploy. Не вставляйте секрет в HTML/браузерный JS/репозиторий и не присылайте в чат.
Серверный маршрут не передает IPA/APK через Function: выполняет перенаправление в GitHub.
При недоступности GitHub не используется устаревшая ссылка Blob.

ВЕРСИИ И ЧЕЙНДЖЛОГ
Мобильные версии извлекаются из текущих имен файлов в GitHub; если номера нет — Latest file.
Версия лаунчера и release notes по-прежнему читаются из daniil179828/Changelog/changelog.json.
Сохраненная резервная копия чейнджлога помечается явно при недоступности живого источника.

ПРОВЕРКА
Структура двух публичных репозиториев и правила LFS просмотрены.
Алгоритм проверен локально с имитацией GitHub API: смена имени, подпапки, Git LFS,
размер, редирект, ошибки, ограничения API и отсутствие зависимостей Blob.
Реальный скачанный IPA/APK и деплой в вашей учетной записи не проверялись.
Открытие HTML с компьютера или GitHub Pages не запускает серверные функции Vercel.
