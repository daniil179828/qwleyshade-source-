QWLEY SHADE — установка на Vercel

1. Отзовите опубликованный в чате Blob-токен и создайте новый. Не отправляйте его в чат.
2. Поместите api/download.mjs и package.json в корень проекта сайта.
   Если package.json уже существует, НЕ заменяйте его: добавьте зависимость @vercel/blob.
3. Замените HTML страницы обновленным файлом. index.html и qwleyshade.html в архиве одинаковые.
   Сохраните существующие assets/ и остальные файлы сайта: их нет в исходном вложении и архиве.
4. В Vercel → Project → Settings → Environment Variables добавьте
   BLOB_READ_WRITE_TOKEN с НОВЫМ токеном этого хранилища (Production; Preview при необходимости).
   Можно подключить Blob к проекту через Connect to Project и проверить переменную.
5. Для обычного HTML-сайта: Framework Preset = Other, без команды сборки,
   Output Directory = корень проекта (.). Install Command = npm install (или автоматически).
   Для существующего проекта с фреймворком не меняйте эти настройки вслепую:
   маршрут api/download.mjs в этом архиве рассчитан на простой HTML-проект Vercel.
6. Выполните новый деплой. Простое открытие HTML на компьютере или GitHub Pages API не запустит.

Работа:
  /api/download?type=ipa — самый поздно загруженный .ipa из ipa/
  /api/download?type=apk — самый поздно загруженный .apk из apk/
Названия файлов могут быть любыми. Папка для iPhone именно ipa/, не ios/.
При нескольких файлах выбирается время загрузки, а не номер версии в имени.
Загрузка старой версии заново сделает ее текущей. Лучше оставлять один актуальный файл в папке.
При пустой папке будет 404; при ошибке хранилища — 502, без старой версии по умолчанию.
Файлы передаются напрямую из Blob, не через Function.
Обращения к API используют операции Blob list; скачивания расходуют трафик Blob.

Windows:
https://raw.githubusercontent.com/daniil179828/QWLEY-SHADE-install-/main/qwley-shade-launcher.exe

Проверено локально с имитацией Blob: выбор последнего файла, фильтр расширения,
пагинация, перенаправление, метаданные, ошибки и недопустимые запросы.
Реальный деплой и скачивание из вашего Blob не проверены.
