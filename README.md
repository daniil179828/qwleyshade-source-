## Изменения этой версии

- Удалены Pass stack / Master FX, боковые маркеры шагов и настройки (кнопка, окно и связанные скрипты).
- Вместо длинной истории прокрутки — один главный экран: Make it yours, описание и кнопки по центру поверх видео, как на образце.
- Windows, iOS, Android и See the shaders остаются на главном экране.
- Иконка Android заменена на узнаваемую голову робота с антеннами и прозрачными глазами; заменены все четыре вхождения.
- Удалён весь нижний раздел Download for iPhone с карточкой IPA, ссылкой COPY и плитками 0 pc / no id / .ipa.
- Прочие разделы и исходное оформление не перерабатывались. Автоматический чейнджлог, фото лаунчера и прежние исправления скачивания сохранены.
- Системный режим уменьшения движения останавливает фоновое видео без отдельного окна настроек.

`public/index.html` и `public/qwleyshade1.html` идентичны. Если предыдущий проект уже установлен, достаточно заменить HTML и добавить `assets/video-poster.jpg`; остальные видео, логотип, скриншот и обработчик скачиваний такие же, как в предыдущем архиве.

Проверены главный экран на 1440 и 390 px, отсутствие удалённых блоков в разметке и сохранение ссылок скачивания. Все восемь изображений сравнений включены в эту версию.

## Новые фото до/после

Добавлены все четыре присланные пары в исходном порядке. В каждой паре первое вложение — BEFORE, второе — AFTER:

2. Хэллоуинская площадь с персонажем.

Кадры четвёртой пары немного различаются по размеру и ракурсу — это свойство исходных снимков; изображения не деформировались для искусственного совпадения.

Дизайн, HTML, CSS, ползунки, видео и скачивания не изменены. Если предыдущая версия сайта уже установлена, достаточно заменить восемь файлов cmp*.jpg в public/assets (на статическом хостинге — в assets). Если старые фото закешировались, обновите страницу с очисткой кеша.

## Публикация на Vercel

1. Добавьте файлы в существующий проект сайта. В архиве теперь есть все восемь фото сравнений. `public/index.html` — основная страница. `public/qwleyshade1.html` — идентичная копия под исходным именем; при необходимости можно оставить только index.html.
2. Framework Preset: Other, Output Directory: public. В корне проекта должны быть `package.json`, `vercel.json` и папка `api/`, а не только HTML.
3. В Storage подключите к этому проекту существующее хранилище `store_zWMJILQpm64NPnwG`. В Environment Variables должна появиться `BLOB_READ_WRITE_TOKEN` именно для этого хранилища. Если Vercel создаёт переменную с другим префиксом, настройте также имя BLOB_READ_WRITE_TOKEN. Секрет хранится только на сервере, не в HTML и не в репозитории.
4. Выполните Redeploy. На опубликованном сайте проверьте реальные скачивания Windows, IPA и APK.

## Файлы из папок, без привязки к имени

iOS: `.ipa` в `ios/` или `ipa/`. Присланная ссылка указывает на `ipa/`, поэтому поддерживаются оба пути.
Android: `.apk` в `apk/` или `android/`.

Функция перебирает все страницы списка Blob, фильтрует расширение и выбирает файл с самой поздней датой загрузки uploadedAt среди папок платформы. Имена можно менять. Тестовые сборки держите в других папках. Повторная загрузка старой версии делает её новейшей по времени загрузки.

Функция не передаёт большой файл через себя — она перенаправляет браузер на актуальный публичный Blob URL с параметром download=1. Приватная панель Vercel не используется как ссылка скачивания.

Windows URL задан на существующий файл в вашем GitHub. Если переименуете EXE, измените WINDOWS_URL в `api/download.js`.

## Проверки и статус

HTML и CSS совпадают с предыдущей согласованной версией; добавлены только восемь фото сравнений. Тесты обработчика: `npm install && npm test`. Реальные мобильные загрузки требуют серверной переменной и проверяются после подключения Blob. На действующем домене ничего автоматически не опубликовано.
