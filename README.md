# Qwley Shade — обновлённый сайт

Готовый проект для Vercel. На действующем домене ничего не изменено автоматически.

## Запуск на Vercel

1. Загрузите содержимое этой папки в репозиторий сайта и импортируйте его в Vercel. Framework Preset: Other. Root Directory: папка с package.json. Output Directory: public (также задана в vercel.json). Build Command не требуется. НЕ публикуйте только public: для мобильных загрузок нужны api/download.js и зависимость @vercel/blob.
2. В Vercel → Storage откройте существующее Blob-хранилище store_zWMJILQpm64NPnwG и подключите проект сайта. Проверьте, что добавлена серверная переменная BLOB_READ_WRITE_TOKEN для Production (и Preview, если нужен предпросмотр). При другом имени переменной измените имя в api/download.js или добавьте её как BLOB_READ_WRITE_TOKEN. Токен должен принадлежать именно этому хранилищу. Нельзя добавлять токен в HTML, браузерный JS или GitHub.
3. Выполните Redeploy после подключения хранилища. Подключите qwleyshade.ru к проекту в Vercel → Settings → Domains, если домен ещё не подключён.
4. Проверьте на опубликованном сайте кнопки Windows, iOS и Android.

## Как выбираются файлы

- iOS: .ipa в `ios/` ИЛИ `ipa/`. Присланный файл находится в `ipa/`, поэтому поддерживаются оба названия папки.
- Android: .apk в `apk/` ИЛИ `android/`.
- Обработчик просматривает все страницы списка Blob, отбирает нужное расширение и выбирает файл с самой поздней датой загрузки (`uploadedAt`). Имена могут быть любыми. Если используются обе папки одной платформы, выбирается новейший файл среди обеих.
- В эти папки загружайте только готовые публичные сборки; тестовые файлы держите в другой папке. При повторной загрузке старой версии она тоже станет «самой новой» по времени загрузки.
- Нет привязки к конкретному имени IPA/APK. Кнопки ведут на `/api/download?platform=ios` и `/api/download?platform=android`. Обработчик отвечает 302 на актуальный Blob URL с `download=1`; сам файл не проходит через функцию и не упирается в лимит размера её ответа.
- Windows: `/api/download?platform=windows` перенаправляет на `https://raw.githubusercontent.com/daniil179828/QWLEY-SHADE-install-/main/qwley-shade-launcher.exe` — файл найден в предоставленном репозитории. Если в будущем переименуете EXE, измените WINDOWS_URL в api/download.js.
- Приватный Vercel URL управления хранилищем НЕ используется как ссылка на скачивание.

## Содержимое

- `public/index.html`, `style.css`, `app.js` — короткая адаптивная страница.
- `public/assets/` — ваш логотип, скриншот лаунчера, оптимизированное видео без звука и постер.
- Видео автоматически проигрывается без звука по кругу. Есть пауза. Системное «уменьшение движения» отключает автопроигрывание; включить видео можно вручную.
- Чейнджлог: `https://raw.githubusercontent.com/daniil179828/Changelog/refs/heads/main/changelog.json`. Показываются две последние записи в порядке источника, до трёх текстовых пунктов. Записи не переводятся и не подменяются.
- Для iOS оставлено предупреждение: загрузка IPA сама по себе не устанавливает приложение. Для установки нужны подходящая подпись и совместимый способ установки.

## Проверка

`npm install`, затем `npm test`: тесты выбора нового имени, расширений, обеих папок, пагинации, Windows, ошибок и ограничения домена Blob. Тесты используют имитацию списка Blob, а не реальный токен.
Для локальной работы функций: `vercel dev` после подключения проекта и переменных. Обычный файловый просмотр HTML или простой статический сервер не выполняет `/api/download`.

Проведена визуальная проверка на ширинах 1440 и 390 px. Успешное скачивание реальных IPA/APK необходимо проверить после подключения хранилища: токен в этой сессии не предоставлялся. Сайт qwleyshade.ru во время подготовки не ответил, поэтому использованы все присланные изображения и видео, без недоступных внешних фото.
