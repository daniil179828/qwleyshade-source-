05 / GET STARTED

Download. Install.
Make it yours.

01Windows

Download the .exe launcher, check that it comes from the linked Qwley Shade repository, then open it and follow the launcher instructions.

Watch the tutorial ↗
02iPhone / iOS

Download the IPA and import it into a compatible installation or signing tool. An IPA does not install by simply opening it in Safari. Tool support, signing requirements, and availability depend on your iOS version and device.

03Android

Download the APK and open it from your Downloads folder. If Android asks, allow installation from that source only if you trust the file. Do not disable device security checks; review any warnings before continuing.
